# 🧠 Noir Puzzles

This repository contains my solutions to the **RareSkills Noir Puzzles**, which are designed to teach the fundamentals of Zero-Knowledge programming using the Noir language.

These exercises focus on learning the core concepts of Noir, such as constraints, witnesses, and how to build simple arithmetic circuits.

---

## ⚙️ Requirements

- Install [Noir](https://noir-lang.org/docs/getting_started/noir_installation)

---

## 🧪 Test Puzzle Solutions

Each puzzle is an independent Noir project.

To run the tests for any exercise:

```bash
cd circuits/<Relevant Puzzle>
````

````bash
nargo test
````
